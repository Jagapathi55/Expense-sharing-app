# 💸 Expense Sharing App

## 📌 Overview
The **Expense Sharing App** is a backend-based application that helps users **manage and split shared expenses** efficiently.  
It allows tracking expenses and calculating balances for groups.

🔗 **GitHub Repo**: https://github.com/Jagapathi55/Expense-sharing-app

---

## 🛠 Tech Stack
- **Backend**: 🚀 Node.js  
- **Framework**: Express.js  
- **Database**: 🗄 MongoDB  
- **Tools**: npm, Git, GitHub  

---

## 🌟 Features
- ➕ Add expenses with amount and description  
- 👥 Manage expense groups  
- 🧮 Automatic expense split calculation  
- 📊 View balance summary  
- 📜 Expense history tracking  

---

## 🛠 System Features
- 🗄 MongoDB for storing expenses and groups  
- 📡 RESTful API using Express  
- 🧹 Structured backend (routes, controllers, models)  

---

## 📑 Validations
- **Expense Amount**: Must be greater than 0  
- **Required Fields**: Amount and description
